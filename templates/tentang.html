Tentang Sistem Rekomendasi

Penjelasan algoritma dan teknologi yang digunakan dalam sistem rekomendasi produk UMKM Kota Kendari

Gambaran Umum

Sistem Rekomendasi Produk UMKM Kota Kendari menggunakan pendekatan Switching Hybrid Recommendation — dua algoritma berjalan secara eksklusif berdasarkan kondisi user: K-Nearest Neighbor (KNN) aktif saat user baru login atau belum cukup memberikan rating (mengatasi cold-start problem), dan Neural Collaborative Filtering (NCF) mengambil alih setelah user memiliki histori rating yang cukup (≥ 3 rating). Sistem secara otomatis beralih (switch) antar algoritma — tidak pernah menggabungkan keduanya sekaligus.

KNN K-Nearest Neighbor

📌 Kapan Digunakan?

Digunakan saat pengguna baru (cold-start) atau belum memberikan cukup rating (< 3 rating).

🔬 Cara Kerja

  1. Feature Extraction — Setiap produk diubah menjadi feature vector:
    • Kategori (One-Hot Encoding)
    • Harga (Min-Max Normalization)
    • Rata-rata Rating (0-5 → 0-1)
  2. Similarity Measurement — Menghitung Cosine Similarity antar feature vector
  3. Anchor Selection — Memilih produk populer sebagai titik acuan
  4. K-Nearest Neighbors — Menemukan K produk terdekat dari anchor
  5. Ranking — Mengurutkan dan memilih Top-N rekomendasi

🎯 Mode Personalized

Jika user mengisi preferensi saat onboarding (kategori favorit & budget), sistem membuat Virtual User Profile Vector dan menghitung similarity terhadap semua produk untuk rekomendasi yang lebih personal.

Formula Cosine Similarity

cos(θ) = (A · B) / (||A|| × ||B||)

Dimana A dan B adalah feature vectors dari dua produk

NCF Neural Collaborative Filtering

📌 Kapan Digunakan?

Diaktifkan saat pengguna sudah memiliki minimal 3 rating dan model NCF sudah di-training oleh admin.

🧠 Arsitektur

Model NCF menggabungkan dua branch:

  1. GMF (Generalized Matrix Factorization)
    • Element-wise product dari user & item embedding → Linear Layer
  2. MLP (Multi-Layer Perceptron)
    • Concatenate user & item embedding → Dense(128) → Dense(64) → Dense(32)
  3. NeuMF (Neural Matrix Factorization)
    • Gabungkan output GMF & MLP → Dense(1, sigmoid) → Prediksi Rating

⚡ Proses Training

  1. Mapping user_id & produk_id ke index berurutan
  2. Normalize score rating (1-5 → 0-1)
  3. Training model dengan Adam Optimizer & Binary Crossentropy
  4. Model disimpan sebagai file .h5

Formula Prediksi NCF

ŷ = σ(h^T [φ_GMF(p_u, q_i) ⊕ φ_MLP(p_u, q_i)])

σ = sigmoid, ⊕ = concatenation, p_u = user embedding, q_i = item embedding

Alur Switching Hybrid Engine

KNN dan NCF digunakan secara eksklusif — sistem memilih salah satu tergantung kondisi user, tidak pernah digabungkan.

1
User membuka halaman Sistem memeriksa status login & jumlah rating
→
2
Belum login / 0 rating? → KNN Cold-Start (produk populer)
→
3
Punya preferensi? → KNN Personalized (kategori + budget)
→
4
≥3 rating + model trained? → NCF (Neural Collaborative Filtering)
